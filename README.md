# ABC 股票形态工作台 · 第一版

一个部署在 Vercel 上的 A 股主板 **首板 → 次日 R1/R3 → 第三天回调 → 第四天开盘观察** 选股网站。纯 Next.js + TypeScript，无需 Python、本地定时任务、GPT API 或付费数据库。

## 已有功能

- 一键拉取最近三个**完整交易日**的涨停池，根据首板股票的历史日 K 检查 A/B/C；默认显示明日 T+3 候选、T+1 提前观察、当日首板三个阶段。
- A / A1 / A1-1 / A1-2 / A2；B / B1 / B1-1 / B1-2 / B2；C / C1 / C2。其中 A1/B1 **必须等到 T+3 的实际开盘价出现才能确认**，不得提前标记。
- 显示 T+1 的 V1、T+2 的 V2、T+2 最低价与 MA5 距离、T+2 上影线、次日开盘价满足 MA5 过滤的区间。
- 支持录入次日实际 9:25 开盘价，立即检查 A1/B1 以及具体子分支。
- 手动输入股票代码，用作公开涨停池失效时的备用发现路径。
- CSV 导出（Excel 可打开）、本机浏览器缓存上次结果、数据更新日期与完整性警告。
- 复权和未复权日 K **同时抓取**：涨停判断依据未复权价格，MA5 和前收比较依据同一套前复权序列；将前复权下的开盘价区间换回真实报价尺度。

## 数据来源

1. 东财涨停池 `https://push2ex.eastmoney.com/getTopicZTPool`
2. 东财股票日 K `https://push2his.eastmoney.com/api/qt/stock/kline/get`
3. 东财个股日 K 请求失败则回退腾讯 `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`

这些均为**非官方公开接口**，可能调整、限制云端 IP、限制历史日期。网页必须展示失败信息，不得把获取失败当成零信号。部署后先打开 `/api/health` 验证 Vercel 服务器是否能访问它们。当前交付环境不能直接联网测试行情，所以**尚未验证 Vercel 到免费接口的实时连通性**。

## 快速启动

1. 将项目文件推送到 GitHub 仓库（或直接拖入支持的部署环境）。
2. Vercel → Add New → Project → Import Git Repository → 选择这个仓库。
3. Framework Preset 选 `Next.js`，根目录为此项目根目录。
4. 建议在 Environment Variables 设置 `SCANNER_PASSWORD`，避免公开网站被他人反复触发高成本刷新。若设置，网页输入相同的刷新口令。
5. Deploy；先访问 `https://你的域名/api/health` 进行源站连通性检查，再打开首页更新。

在可以联网的电脑开发时，命令：

```bash
npm install
npm run dev
npm test
npm run build
```

> `npm test` 是**纯规则测试**，无网络请求；`/api/health` 是**行情连通性测试**。

## 规则详情

统一：T 为首板收盘封住10%涨停，T-1未涨停；T+2 收盘价低于 T+1 收盘价。仅沪深主板，排除 ST / 退市 / 创业板 / 科创板 / 北交所；日 K 少于必要历史或新上市初期不完整的样本不判定。

- **R1**：T+1 阳线实体 >= 当日振幅50%；上下影线占比各 <10%。
- **R3**：T+1 阳线实体 >= 50%；上影线 <10%；下影线 >=10%。
- **A**：R1 + T+1 高开 + V1∈[0.8,1.2) + T+2 回调。
- **B**：R3 + T+1 高开 + V1<0.8 + T+2 回调。
- **C**：R3 + 首板最低价未跌破T-1可比收盘 + V2>=2 + T+2 回调；T+1 不必高开。
- **A1/B1**：T+3 开盘价相对 T+3 **开盘动态 MA5** 的距离为0%～5%。动态 MA5 = (此前4个交易日的可比收盘价之和 + T+3开盘价)/5。
- **A1-1/B1-1**：A1/B1 + T+2最低价在当日收盘MA5上方0%～3%。
- **A1-2/B1-2**：A1/B1但不满足上条T+2条件；**A2/B2**：满足基础A/B但T+3开盘价不满足MA5区间。
- **C1**：C + T+2 上影线占全天振幅 <=20%；**C2**：C但上影线 >20%。

V1=T+1成交量/T成交量，V2=T+2成交量/T+1成交量；均不是交易软件的实时量比。C与B可以重叠，按同一首板事件只算一次。

## 使用边界 / 第二阶段

- 本版基于**最近三个交易日出现涨停的股票池**取数，不会每天抓取所有A股。若公开涨停池缺失，则结果不完整；可以粘贴人工首板名单辅助。
- 当日正在交易时（北京时间15:05之前），不会把当日可能尚未结束的K线当作已完成日线。
- 历史日期筛选受免费接口历史保留限制；缺失数据时明确报错。
- 公司行为、除权、特殊涨跌幅规则、停牌等异常股票在真实交易前需要二次核验。优先采用单只股票的未复权日线检查实际涨停价；前复权日K计算MA5。若T+2到T+3之间发生除权，开盘价区间要重新计算。
- 网站是**当前点击刷新才运行**，没有做后台每天自动定时、跨设备共享的持久数据库、分时图或自动交易。这些是后续阶段。
- 东财或腾讯非官方源的数据口径改变会影响结果，尤其要监测日期、成交量单位和复权因子。

## 代码结构

`src/lib/rules.ts` 纯规则计算（可单元测试）；`src/lib/providers.ts`行情源；`src/lib/scanner.ts`三阶段扫描；`app/api/scan/route.ts`服务端刷新；`app/api/health/route.ts`云端联通检查；`app/page.tsx`前端工作台。
